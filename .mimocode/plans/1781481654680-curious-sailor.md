# Plan: Replace German Mining Deck Definitions with IPA + Context-Aware Meaning

## Goal
Replace the definition field in German mining deck notes with a clean format: **IPA + single meaning matching the sentence context**.

**Key requirements:**
- Plain text format: `IPA - meaning`
- Keep language of original field (Russian for current definitions)
- Fetch IPA from dict.cc if not present in existing data
- Select meaning that matches the sentence context

## Scope
- **Migaku German copy**: 1778 notes → update `Definitions` field
- **Migaku German**: 21 notes → update `Definitions` field  
- **Language Reactor - Word**: 50 notes → update `Word Definition` field
- **Basic (Goethe type)**: 243 notes → **DO NOT TOUCH**

Total: **1849 notes** to process

## Fields to Update
| Note Type | Field to Update | Word Source | Context Source | Phrase Translation Field |
|-----------|-----------------|-------------|----------------|--------------------------|
| Migaku German copy | `Definitions` | `Target Word` | `Sentence` | `Translation` |
| Migaku German | `Definitions` | `Target Word` | `Sentence` | `Translation` |
| Language Reactor - Word | `Word Definition` | `Lemma` | `Context` | `Context Translation` |

**Two updates per note:**
1. Update definition field with `IPA - meaning`
2. Update phrase translation field to highlight target word with `<strong>` tag

## Current State
- Migaku notes have `Definitions` field with:
  - Sometimes IPA in parentheses: `benötigen (bəˈnøːtɪɡən)`
  - Multiple Russian/English definitions
  - HTML markup (`<p>`, `<br>`, etc.)
- Language Reactor notes have `Word Definition` field with:
  - Russian definitions only (no IPA)
- All notes have sentence context in `Sentence` or `Context` field

## Target Format
```
IPA - single meaning (in original field language)
```
Example: `bəˈnøːtɪɡən - нуждаться`

**Language rules:**
- Keep the language of the original field (Russian for current definitions)
- If 1-1 translation is clumsy, use English or add small note in Russian
- Plain text, no HTML markup (except `<strong>` for target word in phrase translation)

**Phrase translation:**
- The phrase/sentence translation must highlight the target word with `<strong>` tag
- Example: "Do you <strong>need</strong> the internet..."

## Implementation Steps

### 1. Create Python script `/tmp/update_definitions.py`

**For each note type, the script will:**

1. **Extract word/lemma**
   - Migaku: Parse `Target Word` field (format: `word[word,part_of_speech,]`)
   - Language Reactor: Use `Lemma` field directly

2. **Extract or fetch IPA**
   - First check if IPA exists in current `Definitions` field (regex for IPA pattern)
   - If not present, fetch from dict.cc API or Wiktionary
   - Fallback: leave word without IPA if unavailable

3. **Analyze context**
   - Migaku: Use `Sentence` field (strip markup)
   - Language Reactor: Use `Context` field (strip markup)

4. **Generate single meaning**
   - Use simple heuristic: check if existing definition has meaning in original language
   - For words with multiple meanings, pick the one that appears in the sentence
   - If 1-1 translation is clumsy, use English or add note in Russian
   - Fallback: use first definition from existing data

5. **Update fields**
   - Migaku: Update `Definitions` field with IPA + meaning
   - Language Reactor: Update `Word Definition` field with IPA + meaning
   - All: Update phrase translation field to highlight target word with `<strong>`

### 2. IPA Source Strategy

**Option A: Extract from existing data**
- Regex pattern: `\(([ˈˈa-zA-Zɪʏʊøːɛɔæəɐ̃ˈˈ]+)\)` in Definitions field
- Many Migaku notes already have IPA

**Option B: Fetch from dict.cc**
- URL: `https://www.dict.cc/?s=WORD`
- Parse response for IPA (look for `/IPA/` pattern in response)
- Rate limit: ~1 request per second to avoid blocking
- Fallback: If no IPA found, leave word without pronunciation

**Option C: Fetch from Wiktionary API**
- URL: `https://en.wiktionary.org/api/rest_v1/page/definition/WORD`
- More reliable but slower
- Returns IPA in response

**Recommendation**: Use Option A first, then Option B as fallback

### 3. Context-Aware Meaning Strategy

**Simple approach (no LLM needed):**
1. Look at existing definition - extract first meaning in original language
2. For words with multiple meanings, pick the one that appears in the sentence
3. If 1-1 translation is clumsy, use English or add note in Russian

**Example:**
- Sentence: "Benötigen Sie das Internet..."
- Word: benötigen
- Existing definition: "нуждаться, требовать"
- Selected: "нуждаться" (matches context)

### 4. Script Structure

```python
# Main flow:
1. Fetch all notes from 3 note types
2. For each note:
   a. Determine note type
   b. Extract word/lemma
   c. Extract sentence context (strip HTML markup)
   d. Extract existing IPA (if any) using regex
   e. Fetch IPA if missing (dict.cc)
   f. Extract/generate single meaning from existing definition
   g. Format: "IPA - meaning" (plain text)
   h. Update definition field via AnkiConnect
   i. Update phrase translation field to highlight target word with <strong>
3. Log progress and errors

# Key functions:
- extract_ipa_from_definition(text): regex for IPA pattern
- fetch_ipa_from_dictcc(word): scrape dict.cc for IPA
- extract_meaning(definition_text, sentence_context, language): 
  - Parse existing definition
  - Pick meaning matching context
  - Return in original language
- highlight_target_in_translation(translation, target_word): 
  - Find target word in translation
  - Wrap with <strong> tag
  - Example: "Do you need..." → "Do you <strong>need</strong>..."
- update_note(note_id, field_name, new_value): AnkiConnect API
```

### 5. Rate Limiting & Error Handling
- Process in batches of 50 notes
- 1 second delay between dict.cc requests
- Save progress to resume if interrupted
- Log all failures for manual review

**Edge cases:**
- Word not found in dict.cc → skip IPA, use meaning only
- Multiple IPA variants → use first one
- Definition field empty → skip note, log warning
- HTML entities in text → decode before processing
- Compound words (e.g., "Lohnangabe") → try whole word first, then split
